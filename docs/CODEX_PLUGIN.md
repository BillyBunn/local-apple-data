# Codex Plugin Packaging

This repo is a local Codex plugin root.

For the public support matrix, see `docs/CAPABILITY_MATRIX.md`. For installation, see `docs/INSTALL.md`. For write and mutation gates, use `docs/MUTATION_GATES.md`, `docs/WRITE_TOOL_ROADMAP.md`, and the machine-checked design-doc inventory in `scripts/audit_write_design_gates.py`. For release readiness, see `docs/PUBLISHING.md`.

Plugin components:

- `.codex-plugin/plugin.json`: local plugin manifest.
- `.mcp.json`: stdio MCP server entry that launches `scripts/run_mcp_server.sh`.
- `scripts/run_mcp_server.sh`: runtime launcher that disables Python bytecode writes, uses the plugin `.venv` when present, falls back to the project `.venv`, then falls back to `uv run --no-project --with mcp`.
- `skills/local-apple-data/SKILL.md`: model-facing workflow rules for using the local data tools safely.
- `skills/local-apple-data/agents/openai.yaml`: Codex UI/dependency metadata for the skill.

## Personal Plugin Sync

Use the checked-in sync helper instead of an ad hoc `rsync` command when
refreshing the configured personal plugin root:

```bash
uv run python scripts/sync_personal_plugin.py --json
codex plugin add local-apple-data@personal
```

The helper uses `rsync --delete --delete-excluded` and excludes local git state,
virtual environments, generated caches, bytecode, build outputs, local Codex
state, local Claude state, `.env*` files, and `.DS_Store` files. This keeps the
personal plugin source and fresh installed cache from retaining ignored local
configuration, Finder metadata, or generated runtime artifacts between installs.

Machine-local launcher configuration that must also reach the installed cache
belongs in `~/Library/Application Support/local-apple-data/.env.operator` (or
the absolute file selected by `LOCAL_APPLE_DATA_OPERATOR_ENV_FILE`). Python
strictly parses only the two helper-ID assignments; it rejects shell syntax,
other keys, symlinks, wrong ownership, and group/world access. The Python
CLI/MCP entrypoint gives a checkout-local `.env.local` precedence. Do not copy either operator
file into the personal root or installed cache. An already-set helper-ID process
environment variable remains the highest-precedence explicit override.

After `codex plugin add local-apple-data@personal`, run runtime checks from the installed cache if runtime or plugin files changed, then run `uv run python scripts/audit_plugin_artifact_hygiene.py --json` again from the source checkout because installed-cache commands can create generated artifacts such as `.venv`. `uv run local-apple-data health --json` is safe because it reports redacted readiness and schema-only checks. Search tools can print local metadata and should only be run for a specific user-requested workflow.
