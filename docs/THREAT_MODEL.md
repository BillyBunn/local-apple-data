The v1.184 exact Mail unsubscribe-metadata gate treats list-header values as
untrusted input. It prevents confused-deputy auto-posts by requiring one exact
message handle, allowlisting only http(s)/mailto URIs, rejecting literal and
percent-decoded controls plus credential-bearing or malformed URLs, and
classifying one-click only when an HTTPS endpoint is paired with the exact RFC
8058 post header. `List-Help`, mailto, HTTP, and non-RFC8058 links remain
manual-required. Rejected values, full/unrelated headers, bodies, raw account
IDs, paths, and endpoint URLs in logs are excluded. The surface performs no
network request or Mail mutation.

The optional body-link mode is off by default and exact-handle-only. It limits
MIME input to 10 MiB, parses HTML anchors without returning body/anchor text,
caps output at five, allowlists URLs through the same endpoint validator, and
rejects generic manage/preferences/login/resubscribe links unless the visible
anchor text explicitly says unsubscribe. Path/query or conservative adjacent
text matches can only produce `classification:body_link`,
`manual_required:true`, and `one_click:false`, preventing body-controlled HTML
from reaching the RFC 8058 auto-POST lane.
